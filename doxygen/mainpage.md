# STM32 core API reference {#mainpage}

This is the source-level API reference of the
[Arduino core for STM32 based boards](https://github.com/stm32duino/Arduino_Core_STM32),
generated with Doxygen from the comments in the core, its built-in libraries,
the STM32 system files and the board variants.

For setup, supported boards, tutorials and the Arduino API, see the
[STM32duino documentation](../index.html). Use the version selector in the
sidebar to switch between the development (`dev`) and the released versions.

## Where to start

- [Classes](annotated.html): classes and structures such as `HardwareTimer`, `HardwareSerial` or `TwoWire`.
- [Files](files.html): browse the documented source files.
- [Functions](globals_func.html): documented C functions.

The ST HAL, LL and CMSIS drivers, the middlewares and the
[ArduinoCore-API](https://github.com/arduino/ArduinoCore-API) sources are not part of this
reference: see their own documentation.
