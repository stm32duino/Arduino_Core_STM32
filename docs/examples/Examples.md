# Examples

Arduino IDE includes built-in examples such as **Blink**. The STM32duino project also provides additional examples for STM32 boards in the [STM32duino Examples](https://github.com/stm32duino/STM32Examples) library.

## Install STM32duino Examples

Install the dedicated examples through Arduino IDE 2:

1. Open **Tools > Manage Libraries**.
2. Search for **STM32duino Examples**.
3. Select the library and click **Install**.

After installation, open them from **File > Examples > STM32duino Examples**. The library contains examples grouped by boards, communication, peripherals, and benchmarking.

The built-in Blink example does not require this library. It is available from **File > Examples > 01.Basics > Blink** after the STM32 core is installed.
