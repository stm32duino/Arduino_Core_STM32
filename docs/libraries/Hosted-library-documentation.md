# Hosted library documentation

Some STM32duino libraries publish API documentation on GitHub Pages, separately
from the core documentation. Use each library's root URL as its stable entry
point; it opens the default release. Add a library here once its hosted
documentation is published. Link to `/dev/` only when explicitly identifying
development documentation.

- [Development API reference](https://stm32duino.github.io/STM32LoRaWAN/dev/)
